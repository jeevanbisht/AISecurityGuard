2. Detailed Component Roles

🔒 Envoy Proxy (Edge Security)
Terminates TLS (Port 8443) or accepts HTTP (Port 8080). Configured with envoy.filters.http.ext_authz. Pauses the downstream HTTP stream until the AI Model Guard approves the request.
🤖 AI Model Security Guard
Receives request metadata (URL, headers, request body). Evaluates queries for SQL Injection, Prompt Injection, or malicious payloads. Responds with 200 OK (Allow) or 403 Forbidden (Block).
🖥️ WebServer Backend
Protected application running on Port 8000. It only receives clean, pre-verified queries that pass the AI Guard inspection. Never exposed directly to raw external traffic.

3. How It Works: Request Execution Sequence

  • 1
    Client Request Arrival
    The client sends an HTTP or HTTPS request containing query parameters or POST payload to the Envoy Proxy endpoint.
  • 2
    Envoy ext_authz Interception
    Envoy's ext_authz filter holds the request stream and issues a sub-request (HTTP POST /check) to the AI Model Guard service containing the request URI, headers, and body.
  • 3
    AI Inspection & Classification
    The AI Model Guard parses the decoded query string and body against heuristic rules and AI classification models (detecting SQLi patterns like UNION, SELECT, OR 1=1 or prompt injection directives).
  • 4
    Authorization Decision & Edge Blocking
    • If Safe: AI Guard returns 200 OK. Envoy releases the held request and forwards it to the WebServer backend.
    • If Unsafe: AI Guard logs a security alert and returns 403 Forbidden. Envoy immediately terminates the request at the proxy edge, returning HTTP 403 to the client without touching the WebServer.
